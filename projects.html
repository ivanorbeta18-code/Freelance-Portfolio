🥗 Ingredient AI

A local AI-powered web app that analyzes a photo of your ingredients and suggests meals you can cook. It uses the LLaVA vision model (llava-phi3, 4-bit) running locally, a Python Flask backend, and a drag-and-drop HTML/CSS frontend.

  • Python
  • Flask
  • LLaVA AI
  • HTML/CSS

⚔️ Tiny Battle

A turn-based strategy game built with HTML5 Canvas and JavaScript. Enemy units navigate the tile map using the A* pathfinding algorithm. Pixel art sprites and maps were designed in LDtk, giving it a retro 8-bit feel. Two teams battle across a grid-based battlefield with a clean HUD showing unit stats.

  • JavaScript
  • HTML5 Canvas
  • A* Algorithm
  • LDtk

📚 NEMSU Library System

A full digital library management system built as a Final System Project for North Eastern Mindanao State University (Surigao del Sur). It includes a librarian admin portal and a student portal, covering book catalog & inventory, student management, borrow & return tracking, reservations, and fine & payment management.

  • Python
  • SQLite
  • HTML/CSS
  • Final Project
